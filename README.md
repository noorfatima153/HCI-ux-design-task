# HCI & UX Design Project

## Project Overview
This repository contains the work completed for the HCI and User Experience practical.

The project focuses on evaluating the University of Agriculture Faisalabad (UAF) Learning Management System (LMS) and redesigning its login page to improve usability.

## Objectives
- Understand the HCI design life cycle.
- Identify usability issues in the existing LMS.
- Suggest improvements to the user interface.
- Create an improved login page wireframe using Figma.

## Project Contents
- **HCI Design Life Cycle:** Overview of the HCI design process.
- **Usability Evaluation:** Identified usability issues in LMS UAF.
- **Screenshots:** Visual evidence of the observed issues.
- **Wireframes:** Redesigned LMS login page.
