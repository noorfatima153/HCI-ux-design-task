# Usability Evaluation Report

## 1. Introduction

The purpose of this evaluation is to identify usability issues in the University of Agriculture Faisalabad (UAF) Learning Management System (LMS). The login page was examined to evaluate its accessibility, functionality, and user experience.

**Website:** https://lms.uaf.edu.pk/

## 2. Identified Usability Issues

### Issue 1: Non-functional Account Links

- **Location:** Login Page
- **Observation:** The options "Register/Activate Your Account" and "Recover your Account" are displayed but are not clickable.
- **User Impact:** New students may face difficulty activating their accounts, while existing students may struggle to recover their accounts.
- **Suggested Improvement:** Make both options functional and link them to their respective pages.

### Issue 2: Missing Password Visibility Option

- **Location:** Login Form
- **Observation:** The password field does not provide a show/hide password option.
- **User Impact:** Users cannot visually verify their passwords while typing, which may lead to input mistakes.
- **Suggested Improvement:** Add a show/hide password button beside the password field.

### Issue 3: Generic Login Error Message

- **Location:** Login Form
- **Observation:** When incorrect login credentials are entered, the website displays the message "Invalid login please try again."
- **User Impact:** The message provides limited guidance to users after an unsuccessful login attempt.
- **Suggested Improvement:** Provide clearer error feedback while maintaining account security.

## 3. Positive Observations

- The login page has a simple and understandable layout.
- The username and password fields are easy to identify.
- Keyboard navigation works on the login page.
- The overall interface is straightforward.

## 4. Conclusion

The evaluation identified usability improvements related to account accessibility, password visibility, and error feedback. Addressing these issues could improve the overall user experience of the LMS.
